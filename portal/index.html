Agente 1 — Análisis + Ficha Preliminar

Analiza fotos del producto, identifica materiales, tipo de envase, y genera una ficha preliminar para revisión.

Inactivo

Pasos del Agente

  1. Recibir foto del producto y datos del fabricante
  2. Analizar imagen con Vision (material, forma, tipo)
  3. Clasificar según CAA (Código Alimentario Argentino)
  4. Generar ficha preliminar en JSON
  5. Mostrar al usuario para revisión

Tools Disponibles

generar_ficha_preliminar DocGen ANMAT

Conexión MCP

DocGen ANMAT node ./mcp-docgen-anmat/src/index.js

Agente 2 — Generación de Documento Final

Toma los datos confirmados y genera el Word/PDF final usando plantillas de Ficha Técnica de Envase.

Inactivo

Pasos del Agente

  1. Recibir ficha confirmada por el usuario
  2. Seleccionar plantilla (Riesgo 2, Silo, Declaración)
  3. Generar documento DOCX con formato ANMAT
  4. Opcionalmente generar Declaración del Fabricante
  5. Guardar en carpeta output/

Tools Disponibles

generar_documento_final DocGen ANMAT
generar_declaracion_fabricante DocGen ANMAT

Agente 3 — Carga TAD (Browser)

Abre browser con Playwright, navega a TAD, completa formulario y sube documentación.

Inactivo

Pasos del Agente

  1. Login en TAD (el usuario completa clave fiscal)
  2. Navegar al formulario de registro de envase
  3. Completar campos del formulario
  4. Subir documentos generados
  5. Verificar con screenshot
  6. Esperar confirmación del usuario para enviar
